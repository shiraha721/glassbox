# Anonymous callbacks and local function expressions

This appendix accounts for the small anonymous functions not given stable names in source: Python lambdas, JSX handlers, React/query effects, state updaters, returned hook commands, and array callbacks. Each has a source link, owning scope, contract category, implementation excerpt, and reason. Larger named functions and the full workflows they compose are explained in the other reference pages. These callbacks are implementation details, not separately supported public APIs.

[Reference index](README.md) · [System architecture](../architecture.md)

## Reading the callback entries

Each file heading states its architectural layer. Each callback inherits that layer and uses its owning function's current parameters/state. **Mechanism** includes the actual source expression/body excerpt, with whitespace normalized and long bodies shortened; the link opens the full implementation. A predicate transforms/chooses data, a render callback constructs React elements, and an event/effect callback may perform I/O through its owner's documented action. No callback is an additional model/tool authority.

For a simple comparison or projection, the expression is the complete mechanism. For a larger handler/effect/test, consult the owner in [Frontend](frontend.md), [Runtime](backend-execution.md), or [Engineering](engineering.md) for the multi-step operation and failure behavior. Line numbers are tied to the reviewed source revision and should be updated when functions move.
